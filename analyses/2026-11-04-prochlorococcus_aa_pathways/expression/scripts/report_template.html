Amino-acid biosynthesis and degradation genes in Prochlorococcus: gene counts and expression calls

Data collection only, no interpretation. Source: multiomics KG 0.1.0-alpha.9. Gene sets: the 14 KEGG pathways under "Amino acid metabolism" (09105), and GO-BP terms named exactly "<amino acid> biosynthetic process" / "… catabolic process" (20 amino acids). Up/down = each paper's own significance call as stored in the KG; no new statistics.

1 · Genes per pathway, per genome

Number of distinct genes annotated to each pathway. Genomes grouped by clade; bold = strain with expression data in the KG. A gene can sit in several pathways. Hover for exact values.

2 · Under which conditions do these genes go up or down?

One row per experiment (grouped by strain), one column per pathway. Each cell has two halves: left = number of the pathway's genes called significantly down, right = number called significantly up, at any timepoint of that experiment. Colour depth = share of the pathway's measured genes. Empty grey = no gene of the pathway has a row in that experiment. The last column gives, for context, the largest share of all measured genes called significant at any one timepoint of that experiment (blank for partial tables, where it is not defined). Hover a cell for the genes, a row label for the experiment design.
